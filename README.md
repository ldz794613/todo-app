# Todo App

一个使用 **HTML + CSS + JavaScript** 开发的简单 Todo 应用，用于练习 **DOM 操作、事件监听、数组管理以及 localStorage 本地存储**。

# 在线访问
https://todo-app-jet-nine-65.vercel.app/

## 功能介绍

* ✅ 添加任务
* ✅ 删除任务
* ✅ 点击任务切换完成状态（删除线）
* ✅ 使用 `localStorage` 保存任务数据
* ✅ 页面刷新后任务仍然保留
* ✅ 显示 / 隐藏已完成任务

## 项目结构

```text
todo-app/
│── index.html
│── style.css
└── script.js
```

### 文件说明

* `index.html`：页面结构（输入框、按钮、任务列表）
* `style.css`：页面样式与完成状态样式
* `script.js`：任务逻辑、事件监听、本地存储实现

## 使用方法

1. 克隆项目

```bash
git clone 仓库地址
```

2. 打开项目文件夹

3. 双击 `index.html` 或使用浏览器打开即可运行

## 技术栈

* HTML5
* CSS3
* JavaScript (ES6)
* localStorage

## 学习内容

本项目主要用于练习：

* DOM 元素获取与操作
* `addEventListener` 事件监听
* 数组增删改查
* `forEach` 遍历
* `classList.toggle()` 类名切换
* `localStorage` 本地数据存储
* `JSON.stringify()` 与 `JSON.parse()`

## 项目预览

可添加任务、删除任务、标记完成，并在刷新页面后保留数据。
